# Monitoring of Road Quality Using Aerial Imagery

A research project investigating the use of **aerial imagery and artificial intelligence** for monitoring road quality.

## 📌 Overview

This project explores the application of computer vision and artificial intelligence to the monitoring and assessment of road infrastructure using aerial imagery.

The work focuses on developing an image-based approach for identifying and analysing road-quality conditions, with the broader objective of supporting more efficient and data-driven road infrastructure monitoring.

## 🎯 Research Focus

The project combines:

* Aerial imagery
* Artificial intelligence
* Computer vision
* Image analysis
* Road infrastructure monitoring
* Transportation engineering

## 🛰️ Data

The research uses aerial imagery for computer-vision-based analysis of road infrastructure.

Processed images and corresponding annotations may be provided in this repository where appropriate.

## 🤖 Artificial Intelligence

The project investigates the application of AI and computer vision techniques to extract information from aerial imagery for road-quality monitoring.

Where applicable, the repository documents:

* Data preparation
* Image processing
* AI-based analysis
* Model development
* Model evaluation
* Research results
